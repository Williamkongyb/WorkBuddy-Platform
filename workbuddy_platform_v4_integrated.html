① 脚本生成 — 4模块智能文案

痛点引入 → 产品卖点+商品卡片 → 信任背书 → 促单话术
支持抖音/小红书/视频号/哔哩哔哩四平台差异化生成，合规违禁词自动扫描修复。

py 1_generate_script.py --product "产品名" --platform douyin

脚本输出路径：D:\WB_Workflow\scripts\

② 视频制作 — 剪映数字人 / Seedance 2.0

主引擎：剪映数字人全自动（pyautogui操控）
备选引擎：Seedance 2.0 API + edge-tts口型同步

py 2_make_video.py        # 剪映主引擎
py 2_make_video_seedance.py  # Seedance备选

视频输出路径：D:\WB_Workflow\final_videos\ | 格式：1080p MP4

③ 自动发布 — Playwright RPA

扫描 final_videos/ → 自动登录抖音/小红书/哔哩哔哩创作平台 → 上传视频+填写标题标签 → 10秒安全暂停确认 → 发布
登录态持久化复用，自动截图调试，发布历史防重复。视频号仅限移动端，自动跳过。

py 3_auto_publish.py

④ 数据监控 — 推流分析+变现闭环

自动抓取抖音/小红书播放量+点赞+评论 → 推流指数分析 → 投流建议+回复草稿
异常预警：2h播放<500 / 完播率低于均值30% / 2s跳出>65%

py scripts/utils/data_monitor.py        # 数据监控
py scripts/utils/ai_super_employee.py  # AI超级员工深度引擎
